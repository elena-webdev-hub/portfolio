
# NORD HOME — Email Marketing Template

Responsive promotional email template for a fictional home decor store.

## Preview

![NORD HOME Email Template](images/preview.png)

## Features

- Table-based email layout
- Inline CSS
- Responsive design
- Mobile-friendly product columns
- Outlook VML button
- Hidden preheader
- Image alt attributes
- Email-safe typography

## Technologies

- HTML5
- CSS3
- Table-based layout
- Inline CSS
- VML
